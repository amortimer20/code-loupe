## Teaching notes

This is the starting point for the library. At Step 1, point out the execution
arrow and ask where the message will appear. Step 2 shows the console output.
The quotation marks delimit a string in the code; the console prints the message
without those marks. No variables or value badges are needed here.

Step backward to see the console return to its empty state. These are two
authored teaching moments for one statement, not two separate lines of code.
The player does not run Python.

Continue with [Simple arithmetic](/samples/python/simple-arithmetic/) to see
a value evaluated before it is printed.

## Try a variation

Replace the message with your own greeting. Update the displayed string,
authored `print` text, and caption together; changing the code alone does not
change the output.
