## Teaching notes

Step 1 introduces the Variables panel: `score` holds the integer 5. Before
Step 2, ask whether `print(score)` will display the word score or the number 5.
The badge comes from the variable row, making the read visible. Step 3 sends
that value to the console while the variable remains unchanged.

Compare this with [Hello, world](/samples/python/hello-world/), which prints a
quoted message directly. Here `score` has no quotation marks and is looked up
as a name. Continue with [Changing a value](/samples/python/changing-value/).

Step backward to remove the output, then return to Step 0 to remove the binding.
The player shows authored states; it does not execute the displayed assignment.
