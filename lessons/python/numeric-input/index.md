## Teaching notes

Pause when `input()` returns `"30"`. Ask whether typing digits makes this value
a number. The `str` tag and quotes make its type visible.

Next, compare `text` and `age` after conversion. Both describe the same entered
age, but only one holds an integer that can participate in subtraction.
