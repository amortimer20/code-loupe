## Teaching notes

Follow [Hello, world](/samples/python/hello-world/) with this lesson. The same
console now receives the result of an expression rather than a literal message.

Pause at Step 1 for a prediction. Step 2 introduces the value badge over `2 + 3`:
its `int` tag identifies 5 as an integer. Step 3 transfers the result to the
console. No named variable stores the value in this example.

Step backward from Step 3 to remove the output while retaining the expression's
badge. Return to Step 1 to hide the badge too. The addition result and output are
teacher-authored; the player does not calculate them or execute Python.

Continue with [Naming a value](/samples/python/naming-value/) to store a number
under a name before printing it.

## Try a variation

Change the addition to `4 + 6`. Update the displayed code, badge `over` target,
badge value to `10`, printed text to `"10"`, and captions. Code changes alone
do not recalculate the lesson.
